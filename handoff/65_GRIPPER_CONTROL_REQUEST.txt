 0. 요약
--------------------------------------------------------------------------------
  1. 신규 5축 팔이 VR 조종에 붙었습니다. 팔은 됩니다. **그리퍼만 안 됩니다.**
  2. 필요한 것은 M-2(손 servo) 때와 **완전히 같은 구조**입니다 → §2
     Command 에 이미 grasp 필드가 있어서 **프로토콜 변경이 없습니다.**
  3. 신규 팔은 AmazingHand 가 아니라 **평행 그리퍼 1자유도**입니다.
     서보 8개가 아니라 **스칼라 하나**면 됩니다. 훨씬 간단합니다 → §1
  4. 제 쪽에서 할 수 있는 건 다 해뒀습니다 (설정 등록·IK·미리보기) → §4


================================================================================
 1. 신규 팔의 그리퍼는 무엇이 다른가
================================================================================

      기존 AmazingHand        서보 8개 / 관절 12개, 평행4절+차동
                              → Command.servo (8개) 로 보냄
      신규 평행 그리퍼         구동 1개 (gripper_joint), 종속 3개
                              → **개구(mm) 스칼라 하나**면 충분

  구조 (64번 §4)

      link5 ─gripper_joint→ rocker_l ─jaw_l_joint(mimic)→ jaw_l
            ─rocker_r_joint→ rocker_r ─jaw_r_joint(mimic)→ jaw_r

  · 조는 회전 없이 **반경 40mm 원호**를 따라 평행이동합니다 (실측 회전량 0.0000°)
  · 개구 0 ~ 58 mm
  · ★ prismatic 으로 근사하면 최대 5.46mm 어긋납니다. 하지 마세요 (64번 §7-(7))

  ★ 종속 관절(jaw_l/jaw_r/rocker_r)은 **명령하지 말 것.** 64번 §7-(4).


================================================================================
 2. ★ 부탁드리는 변경
================================================================================

--- 2.1 Command 에 자리는 이미 있습니다 ---

  grasp 필드(0~1)가 이미 있고 write_positions() 도 이미 받습니다.
  M-2 때 열어주신 그 통로입니다.

      motors.write_positions(q, grasp=..., servo=..., engaged=...)

  → **프로토콜은 바꿀 게 없습니다.** servo 는 None 으로 두고 grasp 만 채우면
    신규 팔에 그대로 씁니다.

--- 2.2 05_teleop_sim.py — 손이 없을 때도 grasp 를 보내주세요 ---

  지금은 `--no-hand` 면 hand 가 None 이라 grasp 가 아예 안 나갑니다.
  신규 팔은 AmazingHand 를 안 쓰므로 **항상 --no-hand 로 돌립니다**
  (hand_mount 프레임이 없어서 안 그러면 죽습니다 — 실제로 겪었습니다).

  즉 지금 구조에서는 **신규 팔에서 grasp 를 보낼 방법이 없습니다.**

  제안 — 트리거 값은 hand 유무와 무관하게 보내기

      grasp = float(right.trigger)          # 이미 계산돼 있습니다
      if hand is not None:
          hand.set_grasp(grasp)
          servo = grasp_to_servo(grasp)
      else:
          servo = None                      # 그리퍼형 팔: 스칼라만
      motors.write_positions(q, grasp=grasp, servo=servo, engaged=armed)

  ★ 지금은 hand 가 None 이면 grasp 도 None 으로 나갑니다. 그 한 줄입니다.

--- 2.3 (선택) 설정에 그리퍼 종류를 적어두면 깔끔합니다 ---

  config/*.json 에 필드 하나를 두면 받는 쪽이 헷갈리지 않습니다.

      "gripper": "amazing_hand"   |   "parallel"   |   null

  없으면 "servo 가 오면 손, grasp 만 오면 그리퍼" 로 구분해도 됩니다.
  급하지 않습니다.

 3. 받는 쪽(Isaac / 젯슨)이 할 일 — 참고
================================================================================

  grasp(0~1) → 개구(mm) → gripper_joint(rad) 변환은
  **assets/arm_new/gripper_map.py** 가 이미 해줍니다 (실측 56점 피팅,
  최대오차 로커각 0.07° / 개구 0.04mm).

      import gripper_map as gm
      opening = grasp * 57.9                 # 0~1 → 0~57.9 mm
      s = gm.servo_for_opening(opening)
      l, r = gm.rocker_deg(s)
      gripper_joint  = radians(45.10 - l)
      rocker_r_joint = radians(r - 52.47)    # nomimic 판만

  제가 뽑아본 대조표 (검산용):

      개구(mm)   서보(deg)   로커 좌/우(deg)   gripper_joint(rad)
      ---------------------------------------------------------
         0.5       27.36     58.94 / 60.23        -0.2415
        10.0       51.81     49.10 / 54.98        -0.0698
        20.0       67.09     39.90 / 49.01        +0.0908
        30.0       80.55     31.29 / 42.73        +0.2410
        40.0       93.96     23.21 / 35.92        +0.3820
        50.0      108.46     15.53 / 28.30        +0.5161
        57.9      120.00      9.97 / 22.22        +0.6131

  ★ mimic 판(arm_new.urdf)은 우측 조에 최대 3.37mm 오차가 남습니다.
    URDF mimic 이 선형만 지원하는데 실제 관계는 비선형이라서입니다.
    정밀 파지 학습에는 **arm_new_nomimic.urdf + gripper_map.py** 를 쓰세요.
    (64번 §4-3)

  ★ 실물 서보는 Feetech STS3215 입니다. 유효 구간 서보 10~120°.
