 3. ★★ 홈 자세 — joint1 영점 이동은 취소. 대신 그리퍼를 180° 돌려 답니다
================================================================================

  ★ 09-02 판에 있던 "joint1 origin rpy [0 0 π] · q1_new = q1_old − 180°" 는
    **취소했습니다.** 기구 담당 지적(71번 §1)이 맞습니다 — joint1 은 팔 전체를
    통째로 돌려서 카메라와 툴의 상대 관계를 못 바꿉니다. 옛 자료를 갖고
    계시면 버려 주세요. **관절값 규약은 원래대로**입니다.

--- 3.0 실물에서 할 일 — 조립 시 그리퍼를 180° 돌려 체결 ---

      그리퍼 조립체를 motor5 장착면(뒷면 M2.5×4, 90° 간격)에서 **180° 돌려** 답니다.
      볼트 홀에 정확히 떨어지고 새 부품이 없습니다 (기구 담당 제안).
      → j5 = 0 에서 카메라가 그리퍼 **위**로 옵니다.

  ★★ **관절 캘리브레이션에는 영향이 없습니다.** motor5 의 영점은 그대로이고
     그리퍼를 돌려 다는 것뿐입니다. joint1 방식과 달리 지령·피드백 오프셋이 없습니다.
     URDF 에는 joint5 origin rpy [0 0 −π] 로 들어가 있습니다 — 이게 그 재체결입니다.

--- 3.1 새 홈 자세 ---

      home_q = [   0.00  -54.51  +84.45  +80.78  +4.90 ]°

  사용자가 VR 로 잡은 자세와 **세계 좌표 형상이 완전히 같습니다** (정면을 보도록
  8° 요만 다릅니다). j2 가 음수인 것은 거울 분지(어깨 뒤로, 팔꿈치 앞으로)라서입니다.

      툴 위치      (+161.2, 0.0, +290.8) mm   수평에서 아래로 20.7°  방위 0°(정면)
      카메라       그리퍼 위 +32.7 mm
      joint1 여유  좌 178° / 우 178°  — 완전 대칭

  ★ 첫 통전 때 팔이 홈으로 **스스로 크게 움직입니다.** 주변을 비우고
    비상 정지를 손에 쥐고 시작하세요. 영점·부호 교정 뒤에 홈 복귀를 누르세요.

--- 3.2 왜 예전 자세가 j1 = -178° 였나 (배경) ---

  카메라가 link5 의 +x 쪽에 달려 있어서, 카메라를 위로 올리려면 팔꿈치를
  반대 분지로 접고 j1 을 반 바퀴 돌리는 수밖에 없었습니다. 그리퍼를 180° 돌려
  달면 j1 = 0 · j5 ≈ 0 의 기계 중립에서 같은 형상이 나옵니다.
