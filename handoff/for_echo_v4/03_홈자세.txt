 2. 어떻게 정했나
--------------------------------------------------------------------------------
   사용자가 **VR 로 직접 팔을 잡고** 원하는 자세를 만든 뒤,
   scripts/13_pose_snapshot.py 로 그 순간의 관절각을 찍었습니다.

       python3 scripts/13_pose_snapshot.py --write config/arm_v2.json

   계산으로 고른 자세가 아니라 **사람이 조종해 보고 고른 자세**입니다.


 3. ★★ joint1 만 제가 고쳤습니다 — -178.00 → -172.00
--------------------------------------------------------------------------------
   사용자가 잡은 원래 값은 joint1 = **-178.00°** 였습니다.
   그런데 이 팔의 joint1 리밋이 **±178°** 입니다. 정확히 붙어 있습니다.

   안전계층에 이런 게 있습니다.

       limit_margin = 0.05 rad = 2.9°

   리밋에서 2.9° 안쪽까지만 허용합니다. 그래서 -178° 를 홈으로 두면
   **실물 기동 순간 -175.1° 로 당겨지며 2.9° 점프**합니다.

   6° 여유를 두면 사라집니다. 대가는 거의 없습니다.

       바뀌지 않는 것    툴 높이 · 툴 각도(아래 20.7°) · 카메라 위치(위 32.7mm)
       바뀌는 것         툴 방위 +2.0° → +8.0°   (팔 전체가 베이스에서 6° 돎)

   ★ 이 자세를 조금이라도 옮길 때는 **joint1 이 ±175° 를 넘지 않는지**
     반드시 확인하세요. 같은 문제가 조용히 되살아납니다.


 4. ★ 왜 joint1 이 리밋 근처로 갈 수밖에 없나 (구조적 문제)
--------------------------------------------------------------------------------
   사용자 요구는 "카메라가 그리퍼 **위**에 오게" 였습니다.
   그런데 카메라가 link5 의 **(35.10, 0.01, 142.45) — +x 쪽**에 달려 있습니다.

   그래서 카메라를 위로 올리려면
       joint5 를 ±110° 이상 돌리거나  (손목 롤 가동범위를 다 씁니다)
       joint1 을 ±178° 근처로 돌리거나  ← 지금 이것
   둘 중 하나입니다.

   ★ **근본 해결은 카메라를 브래킷 반대편(-x)으로 옮기는 것입니다.**
     그러면 joint1 ≈ 0 에서 카메라가 위로 오고 좌우 여유가 생깁니다.
     실물 조립 전이면 지금이 고칠 때입니다. 기구 담당과 상의해 주세요.

   ※ 참고로 홈에서 팔을 한쪽으로 요(yaw)하면 바로 리밋에 닿습니다.
     이게 지금 자세의 유일한 약점입니다.


 5. 다른 자세를 홈으로 쓰고 싶다면
--------------------------------------------------------------------------------
   1) 서버를 띄우고 VR 로 원하는 자세를 만든다
   2) python3 scripts/13_pose_snapshot.py            # 화면에서 먼저 확인
   3) python3 scripts/13_pose_snapshot.py --write config/arm_v2.json
   4) python3 scripts/12_arm_preview.py              # ★ arms.json 재생성
   5) 서버 재시작

   ★ 4번을 빠뜨리면 대시보드 미리보기가 옛 자세로 남습니다.

   확인할 것
       [ ] 모든 관절이 리밋에서 3° 이상 떨어져 있는가  (안전계층 2.9°)
       [ ] 영점(직립) 근처가 아닌가 — 5축 Z-…-Z 구조는 툴 축이 베이스 요축과
           일직선이 되면 j1 과 j5 가 같은 일을 해서 랭크가 무너집니다
           (docs/67 §7-(3))
       [ ] 손목 롤 가동범위가 충분히 남아 있는가
           — 예전에 joint5 가 리밋 근처인 자세를 골랐다가 롤이 -20°/+336°
             로 치우친 적이 있습니다
       [ ] 카메라가 그리퍼 위에 있는가
