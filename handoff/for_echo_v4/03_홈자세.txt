 2. 어떻게 정했나
--------------------------------------------------------------------------------
   사용자가 **VR 로 직접 팔을 잡고** 원하는 자세를 만든 뒤,
   scripts/13_pose_snapshot.py 로 그 순간의 관절각을 찍었습니다.

       python3 scripts/13_pose_snapshot.py --write config/arm_v2.json

   계산으로 고른 자세가 아니라 **사람이 조종해 보고 고른 자세**입니다.


 3. ★★ 그리퍼를 180° 돌려 답니다 — joint1 영점 이동은 취소
--------------------------------------------------------------------------------
   기구 담당 지적(71번 §1)이 맞았습니다. **joint1 은 팔 전체를 통째로 돌리므로
   카메라와 툴의 상대 관계를 못 바꿉니다.** 카메라 위/아래를 정하는 건 j5 입니다.
   그래서 09-02 의 joint1 origin [0 0 π] 는 되돌렸고, 관절값 규약은 원래대로입니다.

   근본 해결 (부품 0개, 기구 담당 제안)
       그리퍼 조립체를 motor5 장착면(뒷면 M2.5×4, 90° 간격)에서 **180° 돌려 체결**
       → j5 = 0 에서 카메라가 그리퍼 위로 옵니다.

   ★★ 실물에서 할 일은 **조립 때 돌려 다는 것뿐**입니다. motor5 영점은 그대로라
      지령·피드백에 오프셋이 없습니다. joint1 방식과 결정적으로 다른 점입니다.

   URDF 로는 joint5 origin rpy [0 0 −π] 가 정확히 그 재체결입니다.
       python3 scripts/16_rotate_joint_zero.py --joint joint5 --deg 180 --urdf ...

   검증 — 사용자가 VR 로 잡은 자세(옛 관습 j1=-172)와 세계 좌표 형상 대조:
       tool_frame · camera_mount · link5 · jaw_l/r  위치차 0.02 mm / 자세차 0.005°
       (정면을 보도록 8° 요만 다릅니다)


 4. 왜 예전 자세가 j1 = -178° 였나 (배경)
--------------------------------------------------------------------------------
   카메라가 link5 의 (35.10, 0.01, 142.45) — **+x 쪽**에 달려 있습니다. 카메라를
   위로 올리려면 팔꿈치를 반대 분지로 접고 j1 을 반 바퀴 돌리는 수밖에 없었고,
   그 자세가 리밋(±178)에 붙었습니다. 그리퍼를 180° 돌려 달면 j1 = 0 · j5 ≈ 0 의
   기계 중립에서 같은 형상이 나옵니다. j1 여유 ±178° 로 완전 대칭입니다.


 5. 다른 자세를 홈으로 쓰고 싶다면
--------------------------------------------------------------------------------
   1) 서버를 띄우고 VR 로 원하는 자세를 만든다
   2) python3 scripts/13_pose_snapshot.py            # 화면에서 먼저 확인
   3) python3 scripts/13_pose_snapshot.py --write config/arm_v2.json
   4) python3 scripts/12_arm_preview.py              # ★ arms.json 재생성
   5) 서버 재시작

   ★ 4번을 빠뜨리면 대시보드 미리보기가 옛 자세로 남습니다.

   확인할 것
       [ ] 모든 관절이 리밋에서 3° 이상 떨어져 있는가  (안전계층 2.9°)
       [ ] 영점(직립) 근처가 아닌가 — 5축 Z-…-Z 구조는 툴 축이 베이스 요축과
           일직선이 되면 j1 과 j5 가 같은 일을 해서 랭크가 무너집니다

       [ ] 손목 롤 가동범위가 충분히 남아 있는가
