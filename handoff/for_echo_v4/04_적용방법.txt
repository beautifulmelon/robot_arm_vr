 3. ★ 자주 걸리는 것
--------------------------------------------------------------------------------

   `Frame with name hand_mount not found in model`
       --no-hand 를 빠뜨렸습니다. 신규 팔에는 AmazingHand 가 없습니다.

   EE 프레임이 camera_mount 로 잡힌다
       EE_FRAME_CANDIDATES 에 tool_frame 이 없습니다.
       config 의 ee_frame 이 "tool_frame" 인지 확인하세요.

   IK 가 이상하게 풀린다 / DOF 가 9로 나온다
       arm_v2.urdf(원본)를 IK 에 물렸습니다. **arm_v2_ik.urdf** 를 써야 합니다.
       placo 는 <mimic> 을 무시해서 종속 관절까지 구동 관절로 셉니다.

   화면에서 그리퍼 조가 안 움직인다
       `<이름>_ik.urdf` 옆에 `<이름>.urdf` 가 있어야 합니다.
       gripper_link.attach() 가 그 규약으로 원본을 찾습니다.

   `TypeError: unexpected keyword argument`
       ArmConfig.load() 는 모르는 키를 거부합니다. config 에 필드를
       임의로 추가하지 마세요.

   실물/브릿지가 명령을 전부 거부한다 (dof_mismatch)
       ★ check_robot_match 가 **config 의 URDF 파일명**과 State 의 robot 을
         대조합니다. 받는 쪽이 보내야 하는 값은 **arm_v2_ik.urdf** 입니다.
         자연스러운 이름(arm_v2.urdf)을 보내면 막힙니다.
         config 에 robot_id 를 두고 그걸 우선 보게 하는 쪽이 낫다고
         제안해 뒀습니다 (docs/68 §5.1). 정해지면 알려주세요.

   헤드셋에서 페이지를 고쳐도 반영이 안 된다
       열려 있던 탭이 옛 코드를 들고 있습니다. **새로고침**하세요.
       02_xr_server_nocache.patch 가 앞으로는 이걸 막아줍니다.

   포트 충돌로 조용히 죽는다
       같은 프로파일을 두 번 띄웠거나 실물 갈래와 겹쳤습니다.
       --profile isaac / test 로 나누세요.


 4. 받는 쪽(젯슨/브릿지)에서 해야 할 일 — 그리퍼
--------------------------------------------------------------------------------
   Command.grasp 에 0.0~1.0 이 **항상** 실려 옵니다. 이 한 줄만 붙이면 됩니다.

       import gripper_map as gm            # assets/arm_v2/gripper_map.py
       opening = 57.9 + (0.5 - 57.9) * clip(grasp, 0.0, 1.0)
       servo   = gm.servo_for_opening(opening)     # 유효 10~120°

   ★ Command 스키마는 안 바뀝니다. grasp 를 무시하면 지금까지와 똑같이 돕니다.
   자세한 것은 docs/68 §2.
