0. 한 장 요약 — 이것만 주셔도 시작할 수 있습니다
--------------------------------------------------------------------------------
 [필수]
   1. hand.urdf 파일
   2. meshes/ 폴더 (.stl 또는 .dae)
   3. 팔 플랜지와 손 밑면 사이의 **장착 변환** (xyz 3개 + rpy 3개, 단위 m/rad)
      -> 커넥터가 URDF 에 이미 포함돼 있으면 "포함됨"이라고만 알려주세요

 [있으면 훨씬 좋음]
   4. 손 전체 질량 (kg)
   5. 관절 8개와 Feetech 서보 ID 대응표
   6. 완전히 편 자세 / 완전히 쥔 자세의 관절각 8개

 폴더 구조는 팔 URDF 와 같은 형태면 됩니다:

     hand/
       hand.urdf
       meshes/
         *.stl

 팔 URDF 도 이 구조로 받아서 스크립트 한 줄로 등록했습니다. 같은 방식이면 바로 붙습니다.


1. ★ 가장 중요 — 팔 URDF 와 **합치지 말고 따로** 주세요
--------------------------------------------------------------------------------
손 관절이 팔 URDF 안에 들어가면 **IK 솔버가 손가락으로 위치를 맞추려 듭니다.**
"컵을 잡으러 가라"고 했을 때 팔은 안 움직이고 손가락만 꼼지락거리는 상황이 됩니다.

  팔  : 5-DOF, IK 로 손목 위치·자세를 만든다      (이미 동작 중)
  손  : 8-DOF, IK 와 무관하게 별도로 지령한다      (트리거/손트래킹으로)

두 URDF 를 따로 두고, 소프트웨어에서 장착 변환으로 이어 붙입니다.
합쳐진 URDF 만 있다면 그것도 받을 수는 있지만, 제가 손 관절을 IK 에서 빼는
처리를 추가로 해야 하므로 분리된 쪽이 확실히 낫습니다.


2. 팔 쪽 인터페이스 — 여기에 붙습니다
--------------------------------------------------------------------------------
파일: assets/robot_arm/robot_arm.urdf  (5-DOF, 총 질량 6.716 kg)

  말단 링크    : link5
  장착 프레임  : hand_mount_link
                 link5 원점 기준  xyz = [0, 0, 0.188503] m,  rpy = [0, 0, 0]

  이 값은 link5 의 visual 메시가 z 축으로 +0.1885 m 까지 뻗은 것을 실측해서 정한
  임시값입니다. 실제 플랜지 면과 다르면 알려주세요. 한 줄로 다시 잡을 수 있습니다.

  link5 메시 범위 (링크 로컬 좌표):
      x  -0.0315 ~ +0.0315   (지름 약 63 mm)
      y  -0.0717 ~ +0.0315   (카메라 브래킷이 -y 로 튀어나옴)
      z  -0.0058 ~ +0.1885

  손목축(joint5) 사양:
      axis = [0, 0, 1]  (z 축 회전 = 손목 롤)
      가동범위 -178° ~ +178°
      토크 20.0 N·m,  속도 3.14 rad/s

  ※ link5 에는 카메라 브래킷도 붙어 있습니다:
      camera_mount : link5 기준 xyz = [-0.00221, -0.07169, 0.16972],
                     rpy = [-1.5708, 0, -3.14159]
     손과 물리적으로 간섭하지 않는지 확인 부탁드립니다.


3. 필요한 것 — 항목별
--------------------------------------------------------------------------------

[3-1] URDF 파일
  * 손 자체의 base 링크 이름을 알려주세요 (예: hand_base_link)
    -> 이 링크가 팔의 hand_mount_link 에 붙습니다.
  * 메시 경로는 상대경로면 좋습니다 (예: meshes/palm.stl)
    package://... 형식이어도 자동 변환하는 스크립트가 있으니 그대로 주셔도 됩니다.
  * 메시가 없어도 기구학은 동작합니다. 3D 화면에서 해당 부분만 안 보일 뿐입니다.

[3-2] ★ 장착 변환 — 이게 없으면 손 위치가 어긋납니다
  팔 플랜지(hand_mount_link) 기준으로 손 base 가 어디에 어떤 방향으로 놓이는지:

      xyz = [ ?, ?, ? ]   단위 m
      rpy = [ ?, ?, ? ]   단위 rad (roll-pitch-yaw, URDF 관례)

  커넥터(어댑터)가 URDF 에 이미 링크로 들어있다면 "포함됨"이라고만 적어주세요.
  커넥터가 별도 부품이면 그 두께/오프셋도 필요합니다.

  ※ 특히 **손바닥이 어느 방향을 보는지**가 중요합니다.
    손목을 0°로 뒀을 때 손바닥이 +x 인지 -y 인지 등. rpy 로 표현해 주시면 됩니다.

[3-3] 관절 정보
  Amazing Hand 는 8-DOF(손가락 4개 × 2축)로 알고 있습니다. 아래를 알려주세요:

      관절이름          손가락    축의 의미        가동범위(rad 또는 deg)
      ---------------- --------- ---------------- ----------------------
      예) index_mcp     검지      굽힘/폄          ?
          index_abd     검지      벌림/모음        ?
          ...

  * URDF 에 limit 이 들어있으면 표는 생략해도 됩니다. 파싱해서 씁니다.
  * mimic 관절(연동 관절)이 있으면 꼭 알려주세요.
    Amazing Hand 는 병렬 링크 구조라 URDF 로 정확히 표현이 안 되는 부분이 있습니다.
    근사로 모델링하셨다면 "근사"라고만 적어주셔도 됩니다.

[3-4] 질량  ★ 팔 부하 재확인에 필요
      손 전체 질량 = ? kg

  참고: 손목축(joint5)은 토크 20 N·m 입니다. 자료상 Amazing Hand 는 약 0.4 kg 인데,
  커넥터까지 더해 손목 끝에 걸리면 팔을 수평으로 뻗었을 때 joint4(20 N·m)에
  걸리는 모멘트를 다시 봐야 할 수 있습니다. 실제 질량을 알려주시면 계산하겠습니다.

[3-5] 자세 프리셋  ★ 조작에 바로 쓰입니다
  VR 컨트롤러 트리거(0.0~1.0 아날로그)로 손을 쥐고 펼 예정입니다.
  그러려면 양 끝 자세가 필요합니다:

      완전히 편 상태  (트리거 0.0) : 관절각 8개 = [?, ?, ?, ?, ?, ?, ?, ?]
      완전히 쥔 상태  (트리거 1.0) : 관절각 8개 = [?, ?, ?, ?, ?, ?, ?, ?]

  중간은 이 둘 사이를 보간해서 씁니다. 핀치(엄지-검지만) 같은 프리셋이 더 있으면
  그것도 주시면 버튼에 배정하겠습니다.


4. 서보 제어 정보 (URDF 와 별개로 필요)
--------------------------------------------------------------------------------
Amazing Hand 는 Feetech SCS0009 서보 8개를 쓰는 것으로 알고 있습니다.
LeRobot 에 Feetech 드라이버가 이미 있어서 그대로 활용할 수 있습니다.

      1. 서보 모델명이 SCS0009 가 맞나요?
      2. 통신 포트 (예: /dev/tty.usbserial-XXXX) 와 보드레이트 (1 Mbps?)
      3. 관절 ↔ 서보 ID 대응표
      4. 각 서보의 회전 방향이 URDF 관절 방향과 같은가요? (반대면 부호를 뒤집습니다)
      5. 영점(서보 중립값)이 URDF 0° 와 일치하나요?

  4·5 번은 실물로 확인해야 하는 값이라, 모르시면 "미확인"으로 두시면 됩니다.
  팔과 같은 절차(소자 상태에서 손으로 움직이며 부호 확인)로 저희가 잡겠습니다.

  ※ 손은 팔(CAN)과 다른 버스(시리얼)를 씁니다. 별개 연결입니다.


5. 받으면 제가 하는 일
--------------------------------------------------------------------------------
  1. hand/ 폴더를 assets/hand/ 로 옮기고 등록
         .venv/bin/python scripts/06_setup_urdf.py --urdf assets/hand/hand.urdf
     -> 관절·한계·자유도를 자동으로 뽑아 config 에 저장

  2. 팔 URDF 의 hand_mount_link 위치를 실제 플랜지에 맞게 재조정
         .venv/bin/python scripts/07_add_tool_frame.py --urdf assets/robot_arm/robot_arm.urdf \
             --hand-offset <x> <y> <z>

  3. VR 화면에 손을 함께 그리기 (팔과 같은 렌더링 모듈을 씀)

  4. 트리거 0~1 → 손 관절 8개 보간, A/B 버튼에 프리셋 배정

  5. 나중에 손 트래킹(엄지-검지 핀치 거리 3~141 mm 실측 확인됨)으로
     손가락별 정밀 제어로 확장


6. 형식 관련 자잘한 것들
--------------------------------------------------------------------------------
  * 단위는 URDF 관례대로 **미터 / 라디안** 이면 됩니다.
    CAD 에서 mm 로 뽑히는 경우가 있으니 확인 부탁드립니다.
    (팔 URDF 는 m 단위였습니다 — 예: link3 길이 0.18875)
  * 좌표 관례는 팔과 맞춰 **z 가 손목 축 방향**이면 이어 붙이기 편합니다.
    다르면 rpy 로 알려주시면 됩니다.
  * .dae 든 .stl 든 상관없습니다. 바이너리 STL 도 읽습니다.
  * inertial(질량/관성) 태그가 없어도 동작합니다. 있으면 부하 계산에 씁니다.
  * 파일이 크면 메시는 빼고 URDF 만 주셔도 시작할 수 있습니다.


7. 질문 있으시면
--------------------------------------------------------------------------------
가장 확실한 건 **CAD 상에서 팔 플랜지 면과 손 밑면이 맞물린 상태의 조립 파일**입니다.
그 상태의 상대 좌표를 알려주시면 3-2 번은 해결됩니다.

우선순위를 매기면:
      1순위  hand.urdf + meshes           (없으면 아무것도 못 함)
      2순위  장착 변환 xyz/rpy            (없으면 손 위치가 어긋남)
      3순위  편 자세 / 쥔 자세 관절각      (없으면 조작 못 함)
      4순위  질량, 서보 ID                (없어도 진행 가능, 나중에 실측)
