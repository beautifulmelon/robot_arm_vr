 1. 손이 움직입니다 — 실측
================================================================================

  Mac --UDP 5015--> Isaac Sim (집 리눅스, 인터넷 너머), 팔은 홈 자세 고정,
  손만 폈다 쥐었다(4초 주기). f1 = 검지의 3관절 실제각(Isaac 물리 결과)입니다.

      grasp    f1_abduction   f1_flexion   f1_distal
      ---------------------------------------------------
      0.04         -0.1          -26.5        -26.0     펴짐
      0.31         -0.0           -2.1         -2.0
      0.70         -0.2          +29.7        +27.3
      0.98         -0.4          +44.2        +37.4     쥠

  ★ 문서값과 정확히 맞습니다.
    Isaac 담당 문서(VR_TELEOP_REQUIREMENTS §7.4):
        "트리거 0.0 → 서보 (-35,+35)  펴짐, 굴곡 -28.9도"
        "트리거 1.0 → 서보 (+90,-90)  쥠,  굴곡 +44.2도"
    실측 grasp 0.98 에서 굴곡 +44.2° — 소수점까지 일치합니다.

  같은 30초 동안 팔은 [-28.2 +15.4 +24.0 -84.2 +11.6]° 에서 **한 번도 안 움직였습니다.**
  손 경로가 팔을 건드리지 않는 것도 같이 확인됐습니다.

  즉 **받는 쪽은 완전히 준비되어 있습니다.** 보내는 쪽만 남았습니다.

 2. ★ 부탁드리는 변경 — 4줄
================================================================================

--- 2.1 src/rpo_teleop/jetson_link.py ---

  Command 패킷에는 servo / grasp 필드가 처음부터 있습니다(79~89행). 다만
  JetsonBackend.write_positions() 가 q 만 받아서 채워 넣을 방법이 없습니다.

      - def write_positions(self, q: np.ndarray) -> None:
      + def write_positions(self, q: np.ndarray, grasp: float | None = None,
      +                     servo: list[float] | None = None) -> None:

            ...
            cmd = Command(session=self.session, seq=self._seq, t=time.time(),
      -                   mode=self._mode, q=list(q), clear_trip=want_clear)
      +                   mode=self._mode, q=list(q), clear_trip=want_clear,
      +                   grasp=grasp, servo=servo)

  기본값이 None 이라 **기존 호출은 전부 그대로 동작합니다.** 두 값이 None 이면
  직렬화에서 필드 자체가 빠지므로 와이어 포맷도 지금과 바이트 단위로 같습니다.
  (이미 그렇게 만들어 두셨더군요 — to_bytes() 의 `if self.grasp is not None`)

--- 2.2 scripts/05_teleop_sim.py ---

  이미 grasp 도 서보각도 계산하고 있습니다. 대시보드로는 보내고 있는데
  (state["hand"]["servo_deg"], 533~534행) 모터로는 안 갑니다.

      495행 근처
      -   motors.write_positions(q)
      +   motors.write_positions(
      +       q,
      +       grasp=None if hand is None else float(grasp),
      +       servo=None if hand is None else [float(v) for v in grasp_to_servo(grasp)],
      +   )

  grasp_to_servo 는 이미 43행에서 import 되어 있습니다.

  ※ 382행·590행의 `motors.write_positions(motors.read_positions())` 는
    그대로 두시면 됩니다 (Quest 대기 중 / 종료 시). 손을 안 보내는 게 맞습니다.

  ★ 정식 통로가 열리면 제 쪽 임시 우회(§3)를 지우고 이 명령으로 다시 확인하겠습니다.

  넣었습니다. write_positions() 를 그대로 복사하고 servo/grasp 두 줄만 더했습니다.

      class HandBackend(JetsonBackend):
          """★ 임시 — jetson_link.py 가 servo 인자를 받게 되면 통째로 삭제할 것"""

  ★ 이건 §2 가 반영되면 **바로 지웁니다.** 복제한 코드라 오래 두면 그쪽이 고친
    버그가 이쪽에 안 옮겨옵니다 — 19번 문서 §3 "양쪽 다 만들지 말 것" 에
    적으신 그대로입니다. 지금은 손 경로를 오늘 검증하기 위한 것이고, 정식
    통로가 열리는 즉시 부모를 직접 쓰겠습니다.

  같은 파일에 하나 더 고쳤습니다 (역시 제 파일).

    · 시작할 때 남아 있는 트립을 한 번 풀어줍니다.
      앞선 실행을 Ctrl+C 로 끊으면 받는 쪽 워치독이 5초 뒤 트립을 겁니다.
      그 상태가 남아 있으면 다음 실행이 **영원히 HOLD 에 머뭅니다.**
      원인을 모르면 "브릿지가 고장났나" 로 보입니다 (Isaac 담당도 같은 걸 겪었습니다).

      ★ 초기 HOLD 창 안에서만 한 번 풉니다. 그 뒤에 걸린 트립은 절대 자동으로
        풀지 않습니다 — 그건 워치독이 진짜로 동작한 것이고 자동 복구는 금지입니다.
        --no-clear-trip 으로 이 동작을 꺼서 트립 자체를 시험할 수도 있습니다.

 4. 왜 관절각이 아니라 서보각이어야 하는가 (실물에도 적용됩니다)
================================================================================

  이 손은 8-DOF 가 아니라 **서보 8개 / 관절 12개** 입니다. 손가락마다 서보 2개가
  평행4절 + 차동 기구로 관절 3개를 움직입니다. 관절이 서로 독립이 아닙니다.

    · URDF 관절 리밋 사각형 중 실제 도달 가능한 조합은 **45.3%** 뿐입니다.
      관절각을 직접 지령하면 실물에 없는 자세를 만들게 됩니다.
    · 보간도 서보 공간에서 해야 합니다. 관절 공간에서 보간하면 양 끝은 같아도
      **중간에서 최대 11.44° 어긋납니다.**

  ※ 이 두 숫자는 저희와 Isaac 담당이 각자 독립적으로 실측해서 같은 값을
    얻었습니다. 기구 담당자 문서와도 일치합니다.

  → 그래서 지령은 servo 8개가 권위 있는 값이고, grasp 스칼라는 로깅용입니다.
    받는 쪽이 servo_to_joint_flat() 로 12관절을 만듭니다. 실물 SCS0009 에는
    서보각이 그대로 나갑니다. **액션 공간이 실물과 시뮬에서 완전히 같아집니다.**
