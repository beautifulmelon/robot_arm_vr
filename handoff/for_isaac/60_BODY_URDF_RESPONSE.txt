 1. 팔은 새로 뽑지 않았습니다 — 받으신 그 URDF 그대로입니다
--------------------------------------------------------------------------------
  본체 CAD 조립본 안에 팔과 손도 같이 들어 있었습니다. 하지만 그걸 다시
  뽑지 않고 **이미 검증이 끝난 팔 URDF 를 글자 그대로 재사용**했습니다.

      urdf_combined/robot_arm_with_hand.urdf  ->  그대로 삽입
      메시 경로(meshes/arm/…, meshes/hand/…)도 손대지 않았습니다.

  이유: 조립본에서 다시 뽑으면 Isaac 자동검증 14/14 를 통과한 그 모델과
  미세하게 달라질 수 있습니다. 팔은 바꿀 이유가 없으니 그대로 둡니다.

  본체 URDF 는 조립본에서 **팔·손·손목·D435·baselink 를 전부 제외**하고
  본체 부품 28개만 뽑았습니다.

  ※ 조립본의 팔은 joint3 이 URDF 영점 대비 180° 돌아간 자세로 놓여 있었습니다.
    부착 위치와는 무관합니다 (joint1 원점과 베이스 자세만 쓰기 때문).
    확인 방법: 조립본 회전관절 5개의 상대 위치가 팔 URDF 와 일치합니다.
        Rev20 (-20, 0,  56.00)  =  joint2 (-20, 0,  56.00)
        Rev21 (  0, 0, 106.00)  =  joint3 (  0, 0, 106.00)
        Rev27 (  0, 0, 344.75)  =  joint5 (  0, 0, 344.75)
    joint4 만 x 부호가 반대인데, joint3 이 180° 돌면 정확히 그 패턴이 됩니다.


 2. 후상방 카메라 — 이미 CAD 에 있었습니다
--------------------------------------------------------------------------------
  요청 §3 에서 "붙일 데가 없다"고 하셨는데, 본체 CAD 에 **Logitech C920 이
  이미 모델링돼 있고 cam2 라는 조인트 오리진까지 잡혀 있었습니다.**
  그 값을 그대로 썼습니다. 새로 만든 게 아닙니다.

      cam2 원점  = C920 전면 중앙과 정확히 일치 (bbox 중앙 대비 0.00 mm)
      cam2 축    = ROS optical 규약과 정확히 대응

  ★ 카메라는 **기울어져 있지 않고 수평(+X)** 을 봅니다.
    (C920 bbox 의 x 폭이 24.02 mm 로 카메라 두께 그대로입니다. 기울었다면
     bbox 가 그보다 커집니다)

  시야 계산 (C920 78° 대각 = 수평 70.4° / 수직 43.3°, 16:9 기준)

      대상            전방거리    수직각     판정
      -----------------------------------------------------
      hand_mount       347 mm    -9.3°     시야 안
      팔 base_link     347 mm   -59.5°     시야 밖

      전방 거리별로 덮는 높이 (z, mm)
        300 mm 앞 :  z  655 ~  893   폭 ±212
        500 mm 앞 :  z  576 ~  973   폭 ±353
        800 mm 앞 :  z  457 ~ 1092   폭 ±564
       1200 mm 앞 :  z  298 ~ 1251   폭 ±847

      바닥(z=0)이 화면에 들어오기 시작하는 거리 = 약 1951 mm 앞

  ★★ 카메라 시점을 실제로 렌더해봤습니다. 두 가지가 나왔습니다.

    (1) **홈 자세(전 관절 0)에서는 손이 화면을 거의 다 가립니다.**
        카메라에서 손까지 347 mm 뿐이라 손이 화면을 꽉 채웁니다.
        -> renders/body_camview.png

        데이터 수집 시작 자세를 전 관절 0 으로 두면 후상방 카메라가
        사실상 손만 보게 됩니다. 팔을 옆으로 내리거나 낮추는 홈 자세가
        따로 필요합니다.

        ※ 어차피 전 관절 0 은 기구학적으로도 특이점입니다
          (자코비안 랭크 3/5, 특이값 2개가 정확히 0). 홈 자세로 쓰면
          안 되는 자세인데, 시야까지 막힌다는 근거가 하나 더 생겼습니다.

    (2) 팔이 비켜나면 테이블(높이 700 mm)과 그 위 컵이 모두 시야에
        깔끔하게 들어옵니다.  -> renders/body_camview_reach.png

  ★ 확인 부탁드릴 것
    작업 영역(컵·거치대)이 **어느 높이**에 놓이는지에 따라 시야가 갈립니다.
    - 테이블 위(z ≈ 700~800)면 지금 그대로 잘 보입니다.
    - 바닥 가까이(z < 300)면 2 m 가까이 떨어져야 보입니다.
    후자라면 카메라를 아래로 기울이는 게 낫습니다. 각도만 정해주시면
    CAD 수정 없이 URDF 에서 반영할 수 있습니다.


 3. 팔 부착 — 조립본 실측 그대로
--------------------------------------------------------------------------------
      arm_mount              ( 314.38,  -0.02, 184.46) mm,  회전 없음
      -> 팔 base_link 가 여기 놓입니다 (arm_attach_joint, origin 전부 0)

  본체+팔 조립 후 주요 지점 (body_base 기준, mm)

      base_link      ( 314.38,  -0.02,  184.46)
      link5          ( 314.38,  -0.02,  529.21)
      hand_mount     ( 314.38,  -0.02,  717.71)
      camera_mount   ( 312.16,  -71.71,  698.93)   손목 D435
      hand_base      ( 314.38,  -0.02,  717.71)    손 +Z = (0,0,+1) 손끝 위

  ★ §7 에서 "팔 작업공간을 본체 기준으로 다시 계산" 하시겠다고 했는데,
    변환은 단순합니다. 기존 어깨 기준 값에 아래를 더하시면 됩니다.

        (+314.38, -0.02, +184.46) mm

    팔 base_link 프레임의 회전이 body_base 와 완전히 같기 때문입니다
    (회전 없음). 축 정렬을 다시 하실 필요 없습니다.

  ※ 팔 base_link 형상은 프레임보다 56.5 mm 아래로 내려가므로 본체 좌표로는
    z = 127.96 mm 까지 내려옵니다. 본체 프레임 레일(z 80~120)과 x 로
    62.8~67.3 구간이 4.5 mm 겹칩니다. body_base ↔ base_link 는 fixed 로
    직접 연결돼 있어 부모-자식 접촉 필터에 걸리므로 물리적으로 문제되지
    않습니다. 실물에서는 볼트 체결부라 정상입니다.


 4. ★ 질량은 CAD 값이라 믿지 마세요

    팔+손 2.72 kg 대비 30배입니다.

  ★ 그리고 더 확실한 방법을 권합니다.

 5. 메시 — §5 요청대로 나눴습니다
--------------------------------------------------------------------------------
      visual     본체 부품 28개의 STL 그대로 (15.0 MB)
      collision  부품별 **방향 상자(oriented box) 28개**

  요청하신 대로 collision 을 단순화했습니다. 삼각형 메시가 아니라 박스라
  물리 계산이 가볍고, 부품 로컬 축을 그대로 상자 축으로 써서 월드 AABB 처럼
  헐거워지지도 않습니다.

  ※ 팔/손은 기존 그대로(visual = collision = 풀해상도 STL)입니다.
    바꾸면 검증본과 달라지므로 건드리지 않았습니다.
