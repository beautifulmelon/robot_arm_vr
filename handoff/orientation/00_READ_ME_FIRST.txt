  VR ↔ 로봇팔 방향이 안 맞을 때 쓰는 묶음입니다.
  저희(Mac/WebXR/IK 담당)가 같은 문제를 한 번씩 다 겪고 실측해둔 값들입니다.


 1. 지금 당장 해볼 것 (코드 안 고침, 10초)
--------------------------------------------------------------------------------
      헤드셋 안에서   왼손 X = 미러 토글      왼손 Y = yaw +90°

  yaw 4가지 × 미러 2가지 = 8조합입니다. **손 좌표가 RUB(y-up)이기만 하면
  이 8개 중 하나는 반드시 맞습니다.** 여기서 맞으면 §3 만 읽고 끝내세요.

  8개 다 돌려도 안 맞으면 좌표계 자체 문제입니다 → 가이드 §2.


 2. ★ 뷰어 띄우기 — 8조합을 눈으로 비교 (제일 빠릅니다)
--------------------------------------------------------------------------------
      python3 viewer/serve_viewer.py            →  http://localhost:8770
      python3 viewer/serve_viewer.py --urdf 자기URDF.urdf

  관절 슬라이더 + yaw/미러 버튼입니다. 화면에 **로봇 좌표축**(빨강 앞 /
  초록 왼쪽 / 파랑 위)을 같이 그려서, yaw 를 바꾸면 로봇의 앞이 화면
  어느 쪽으로 가는지가 바로 보입니다.

  ★ 그리는 코드는 헤드셋 안에서 쓰는 **robot_view.js 그대로**입니다.
    여기서 보이는 것이 VR 에서 보이는 것과 같은 규약입니다.

  numpy 만 있으면 돕니다. placo·pinocchio·ROS·STL 전부 필요 없습니다.
  (기구학은 순수 numpy 로 넣고 pinocchio 와 대조 검증했습니다 — 오차 1.7e-16 m)


 3. 자기 팔의 방향표 뽑기 (숫자로)
--------------------------------------------------------------------------------
      python3 check_orientation.py                       # 동봉된 팔 2종
      python3 check_orientation.py 자기URDF.urdf          # 자기 팔

  ★ 여기서 나오는 **"관절을 +로 돌리면 손끝이 어디로 가는가"** 표를
    실물 옆에서 대조하세요. 이게 없으면 무엇이 "맞는 것"인지 기준이 없습니다.


 4. 증상으로 찾기
--------------------------------------------------------------------------------
      28_ORIENTATION_GUIDE.txt  §1  증상 → 원인 표
                                §11 진단 절차 (이 순서대로 하세요)

  ★ 절차의 0단계가 제일 중요합니다 — **손을 쓰지 말고 실물을 손으로 움직여**
    화면과 비교하는 것. 여기서 "표시 문제 / 제어 문제" 가 갈립니다.
    이걸 안 하고 시작하면 두 문제를 동시에 쫓게 됩니다.

  ★ 그리고 **한 번에 하나만** 바꾸세요. 둘을 같이 만지면 서로 상쇄해서
    "가끔 맞는" 상태가 되고, 그게 제일 오래 걸립니다.

 6. 제일 자주 나온 3가지 (미리 말씀드립니다)
--------------------------------------------------------------------------------
  ① 회전 합성 순서를 좌우 바꿔 씀 → 축이 **170.4°** 어긋납니다. §4
     위치는 완벽하고 회전만 이상해서 IK 를 의심하게 됩니다. 아닙니다.
     ★ home 자세가 항등행렬이면 좌우 곱이 같아서 **테스트가 통과합니다.**

  ② 손목 롤 축을 코드에 박음 → 팔마다 **부호가 반대**입니다. §5
     저희 임시 팔은 마지막 관절이 아예 안 움직였습니다(오차 177.7°).
     자세는 soft task 라 **예외도 안 나고 로그도 깨끗합니다.**

  ③ 화면 뷰 변환을 링크마다 적용 → 형상이 흩어집니다. §6-1
     **루트 그룹에 한 번만** 걸어야 합니다.
