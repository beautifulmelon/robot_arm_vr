 1. 랭크 문제 재현
--------------------------------------------------------------------------------
  요청 구성(A: base_link + link1 + link2 + link5, link3 자리에 link5)에 대해
  독립적으로 측정했습니다.

  1-1) joint3 단독 영향
       joint1 = +17.2°, joint2 = -28.6° 로 고정하고 joint3 만 ±178° 전 범위
       101점으로 돌렸을 때 hand_mount 위치 변화

           최대 = 0.000000 mm

  1-2) 위치 자코비안 랭크
       리밋 안에서 임의 자세 300개, 중앙차분(h=1e-6)으로 3×3 위치 자코비안

           랭크 3 : 0개
           랭크 2 : 300개      <- 전부
           랭크 1 : 0개

           특이값 중앙값 = [0.2385, 0.1828, 0.0000]
           3번째 특이값 최댓값 = 0.000e+00

  1-3) 원인
       joint3 origin rpy = 0 0 0, axis = 0 0 -1  (link2 프레임 기준 z)
       hand_mount origin xyz = 0 0 0.18850348    (link5 프레임 기준 z)

       joint3 의 회전축과 hand_mount 오프셋이 같은 직선 위에 있습니다.
       축 위의 점은 그 축을 중심으로 회전해도 움직이지 않습니다.

       -> joint3 은 손목 롤(자세 1자유도)만 담당하고 위치에는 기여 0.
       -> 위치 자유도는 joint1, joint2 둘뿐.

  요청 문서 §0 의 진단과 완전히 일치합니다.


 2. 대안 비교
--------------------------------------------------------------------------------
  전체 5-DOF 팔 URDF 에서 발췌해 세 구성을 합성하고, 각각 임의 자세 600개로
  측정했습니다.

    리치      = base_link 원점에서 hand_mount 까지의 3D 거리
    같은방향
    거리폭    = 원점에서 본 방향이 거의 같은(단위벡터 내적 > 0.999) 점들끼리의
                리치 차이, 그 중앙값. 0 에 가까우면 손끝이 곡면 위에서만
                움직인다는 뜻입니다.

    구성                              위치랭크   리치(mm)      같은방향 거리폭
    --------------------------------------------------------------------------
    A 요청: link3자리 link5, 요        2      236.1~294.5      0.3 mm   껍질
    B 같은자리 축만 피치(1 0 0)        3       82.6~293.5     46.2 mm   부피
    C 제안: link4자리 link5            3      203.6~482.6    109.0 mm   부피

  A 는 거리폭 0.3 mm 로, 사실상 두께 없는 구면 위만 훑습니다.
  요청 문서에서 재신 2.4 mm 와 같은 결론입니다 (샘플링 방식 차이로 값만 다름).


 3. 제안 구성(C) 상세
--------------------------------------------------------------------------------
      base_link -j1- link1 -j2- link2 -j3- link3 -j4- link5
                                                     +- (fixed) camera_mount
                                                     +- (fixed) hand_mount - 손

  전체 5-DOF 팔에서 **link4 하나만 빼면** 됩니다. 새로 만들 부품이 없습니다.
  joint4 가 요청 문서 §1 에서 말씀하신 피치 축(axis = 1 0 0)입니다.

  관절

    관절     부모 -> 자식        origin xyz            axis      리밋
    ---------------------------------------------------------------------
    joint1   base_link -> link1  0 0 0                 0 0 -1    ±178°
    joint2   link1 -> link2      -0.02 0 0.056         -1 0 0    ±100°
    joint3   link2 -> link3      0.02 0 0.05           0 0 -1    ±178°
    joint4   link3 -> link5      0.02 0 0.18875        1 0 0     ±120°
                    (원본에서는 자식이 link4)

    joint1~joint3 은 원본과 완전히 동일합니다 (부모/자식 포함).
    joint4 는 자식만 link4 -> link5 로 바뀌고 origin/axis/limit 은 원본 그대로.
    모든 관절 origin 의 rpy 는 0 0 0.

    effort 27.0 N·m (피크), velocity 3.77 rad/s.
    모터 DM-J4340P-2EC, 40:1, 정격 9 N·m / 피크 27 N·m.

  기본자세 링크 위치 (base_link 프레임 기준, mm)

    link1          (   0.00,    0.00,    0.00)
    link2          ( -20.00,    0.00,   56.00)
    link3          (   0.00,    0.00,  106.00)
    link5          (  20.00,    0.00,  294.75)
    camera_mount   (  17.79,  -71.69,  464.47)
    hand_mount     (  20.00,    0.00,  483.25)

  질량   팔만 2.2949 kg / 손 포함 2.6949 kg
  도달   hand_mount 수평반경(xy) 15.0~426.7 mm, z -174.5~483.3 mm (28561자세)
         원점 기준 3D 리치는 203.6~482.6 mm (위 §2 표와 같은 기준)

  관절별 최악 중력토크 (리밋 전범위 28561자세 탐색)

    관절     매단질량     최악 토크      정격(9 N·m) 대비
    -------------------------------------------------------
    joint1   2.2541 kg    0.000 N·m       0.0%   (축이 수직)
    joint2   1.8537 kg    4.886 N·m      54.3%
    joint3   1.8301 kg    1.305 N·m      14.5%
    joint4   0.9479 kg    1.326 N·m      14.7%

  joint2 가 정격의 54% 입니다. 전체 5-DOF 팔의 60% 보다 낮습니다.

 5. 자기충돌
--------------------------------------------------------------------------------
  MuJoCo 볼록껍질 접촉 판정으로 리밋 전 범위를 격자 스윕했습니다.
  (PhysX 가 보게 될 것과 같은 방식)

    A : 관절 3개 × 27점 = 19683 자세
    C : 관절 4개 × 27점 = 531441 자세

  두 구성 모두 접촉 2쌍이 나오는데, **둘 다 전체 5-DOF 팔에도 똑같은 깊이로
  존재하는 기존 항목**입니다.

    쌍                                 최대침투   전체팔   비고
    ---------------------------------------------------------------------
    link1 <-> base_link                3.25 mm   동일    joint1 힌지 물림. 정상
    hand_base <-> hand_f4_proximal    10.17 mm   동일    손 내부 기존 문제

  -> 임시 구성이 만든 신규 자기충돌은 A, C 모두 없습니다.
     관절 리밋 전 범위를 그대로 쓰실 수 있습니다.

  ※ 자기충돌은 반드시 볼록껍질 기준으로 보셔야 합니다.
    AABB/OBB 상자 기준으로는 긴 링크가 회전할 때 상자가 부풀어
    있지도 않은 겹침을 30 mm 씩 오보합니다. 저희도 처음에 그렇게 나왔다가
    렌더와 접촉 판정으로 오보임을 확인했습니다.


 6. 알려진 함정
--------------------------------------------------------------------------------
  1. 메시 단위가 섞여 있습니다. 통일하면 깨집니다.
       팔 STL          mm 단위, scale="0.001 0.001 0.001"
       손 STL (MJCF계)  m 단위, scale 없음
       손 셸 STL        mm 단위, scale="0.001 0.001 0.001"

  2. Merge Fixed Joints 를 켜면 camera_mount / hand_mount / hand_base 가
     사라집니다. hand_mount 를 --ee-frame 으로 쓰시려면 꺼두세요.

  3. _nomimic 판은 손 관절을 전부 명령해야 합니다. 8개만 주면 손끝이 늘어집니다.
     mimic 판(_with_hand)을 쓰시면 8개만 주면 됩니다.

  4. 손 제어는 관절각이 아니라 **서보각**을 액션으로 쓰세요.
     관절 리밋 사각형의 55% 는 실물에서 나올 수 없는 조합입니다.
     변환 모듈은 앞서 드린 servo_map/ 에 있습니다.

  5. base_link 형상이 프레임보다 56.5 mm 아래로 내려갑니다. 배치 시 띄우세요.

  6. 팔 drive gain 을 손에 그대로 쓰면 손가락이 발작합니다. 두 자릿수 차이입니다.
     (팔 1000/50, 손 1000/20)


 7. 재현 방법
--------------------------------------------------------------------------------
  이 패키지의 URDF 는 전부 전체 5-DOF 팔 URDF 에서 자동 발췌한 것입니다.

      python3 build_temp_urdf.py                          # A
      TEMP_ARM_CONFIG=temp_arm4 python3 build_temp_urdf.py  # C

  구성을 바꾸시려면 build_temp_urdf.py 의 CONFIGS 만 고치면 됩니다.

      "temp_arm4": dict(
          keep_links=["base_link","link1","link2","link3","link5"],
          keep_joints=["joint1","joint2","joint3"],
          splice="joint4", old_child="link4", drop=["link4"]),

  B 안(축만 피치로)이 필요하시면 말씀 주세요. 바로 뽑아 드립니다.
