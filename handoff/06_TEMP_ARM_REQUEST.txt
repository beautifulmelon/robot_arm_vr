 임시 테스트 팔 (3-DOF) — URDF 전달 요청
================================================================================
 작성일 : 2026-08-04
 대상   : URDF/기구 담당
 목적   : 실물 5-DOF 팔을 쓰기 전에 짧은 팔로 텔레옵 파이프라인을 검증
 구성   : base_link + link1 + link2 + link5 + 손  (link3 자리에 link5)
================================================================================


 0. ★★ 먼저 읽어주세요 — 만들기 전에 확인이 필요합니다 ★★
--------------------------------------------------------------------------------
  "link3 자리에 link5 를 그대로 넣는다"를 현재 URDF 값으로 합성해서 기구학을
  먼저 재봤습니다. 결과가 좋지 않습니다.

    ┌──────────────────────────────────────────────────────────────┐
    │  제3관절을 joint3 그대로(요, 축 0 0 -1) 두면                  │
    │  손끝이 2차원 '껍질' 위에서만 움직입니다. 부피가 아닙니다.     │
    └──────────────────────────────────────────────────────────────┘

  실측 (합성 URDF 로 확인):

      joint3 을 ±178° 전 범위로 돌려도 hand_mount 위치 변화 = 0.0000 mm
      자코비안 위치 3행의 랭크 = 300개 임의 자세 전부 **2** (3 이어야 정상)
      같은 방향에서의 도달 거리 폭 = 중앙값 2.4 mm (사실상 하나의 면)

  이유:
      joint3 의 회전축이 z 이고, link5 안에서 hand_mount 오프셋도
      [0, 0, 0.18850348] 로 **같은 z 축 위**에 있습니다.
      축 위의 점은 그 축으로 아무리 돌려도 제자리입니다.
      -> joint3 은 손목 롤(자세)만 바꾸고 위치는 전혀 못 바꿉니다.
      -> 위치 자유도가 joint1, joint2 둘뿐 = 2-DOF

  이대로 만들면 텔레옵 테스트가 거의 불가능합니다. 손을 앞뒤로 뺄 수가 없고
  정해진 곡면 위에서만 미끄러지듯 움직입니다.


 1. ★ 해결책 — 제3관절을 '피치'로 (요가 아니라)
--------------------------------------------------------------------------------
  네 가지 구성을 합성해서 비교했습니다:

    제3관절 구성                     위치랭크   리치(m)        같은방향 거리폭
    ------------------------------------------------------------------------
    joint3 그대로 (요, 축 0 0 -1)       2     0.183~0.295      2.4 mm  ❌ 껍질
    축을 x 로 (피치, 축 1 0 0)          3     0.083~0.294     88.6 mm  ✅ 부피
    축을 y 로 (피치, 축 0 1 0)          3     0.083~0.294     81.5 mm  ✅ 부피
    요 유지 + 링크 90° 눕힘             2     0.189~0.216      4.0 mm  ❌ 껍질

  ★ 권장: 제3관절의 회전축을 **link5 가 뻗는 방향에 수직**으로 두세요.
    즉 손목 비틀기(요)가 아니라 **팔꿈치처럼 굽히는 축(피치)** 이어야 합니다.
    현재 팔에서는 joint4 가 그런 축입니다 (axis = 1 0 0).

  실물 조립 시:
      세 번째 모터를 joint3 자리가 아니라 **joint4 와 같은 방향**으로 붙이세요.
      (모터 회전축이 링크 길이 방향과 수직)

  ※ 요 축 하나를 꼭 넣고 싶으시면 4-DOF (요+피치+피치 또는 요+피치+요) 로
    가시는 게 낫습니다. 3-DOF 로 위치를 다 커버하려면 축 셋이 서로
    독립이어야 합니다.


 2. 넘겨주실 것
--------------------------------------------------------------------------------
  [필수]
    1. robot_arm_temp.urdf
    2. meshes/  (기존 팔과 같은 STL 이면 재사용해도 됩니다. 아래 §4 참고)

  폴더 구조는 기존과 동일하게:

      robot_arm_temp/
        robot_arm_temp.urdf
        meshes/
          *.stl

  놓을 자리는 이미 만들어뒀습니다:  assets/robot_arm_temp/

  [URDF 에 반드시 들어가야 할 것]
    * hand_mount 프레임 — 손이 여기 붙습니다. 현재 값과 동일하게:
          <joint name="hand_mount_joint" type="fixed">
            <parent link="link5"/> <child link="hand_mount"/>
            <origin xyz="0 0 0.18850348" rpy="-1.570796327 0 0"/>
          </joint>
      이름이 hand_mount 가 아니어도 되지만, 다르면 알려주세요
      (--ee-frame 으로 지정하면 됩니다).

    * 관절 limit / effort / velocity — 실제 가동범위로. 없으면 ±180° 로 가정하는데
      그러면 IK 가 관절을 한 바퀴 감는 문제가 생깁니다 (지난번에 겪은 것).

    * camera_mount 는 필요 없으면 빼셔도 됩니다.


 3. 확인만 하고 싶으실 때
--------------------------------------------------------------------------------
  URDF 를 주시면 제가 아래를 자동으로 재서 알려드립니다. 만들기 전에 먼저
  URDF 만 보내주셔도 됩니다.

      .venv/bin/python scripts/06_setup_urdf.py --urdf <파일> --out config/arm_temp.json

  출력되는 것:
      자유도 / 관절 한계 / 총 질량
      작업공간 bbox 와 리치, 스케일 계수
      특이점 회피 홈 자세 + 자코비안 조건수
      IK 성능 3종 (솔버 품질 / 자유도 충분성 / 연속 추종)

  ★ 위 §0 의 랭크 문제는 "② 자유도 충분성" 과 "③ 연속 추종" 에서 드러납니다.
    랭크가 부족하면 ③ 의 위치오차가 크게 뜹니다.


 4. 메시에 대하여
--------------------------------------------------------------------------------
  임시 팔이 기존 부품(base_link, link1, link2, link5)을 그대로 쓴다면
  메시도 그대로입니다. 그 경우 URDF 안의 경로만 맞으면 되고, 두 방법이 있습니다:

    (a) meshes/ 를 복사해서 같이 주기          ← 가장 확실
    (b) URDF 의 filename 을 ../robot_arm/meshes/*.stl 로 두기
        (assets/ 아래 나란히 놓이므로 상대경로가 통합니다)

  ※ scale 속성 주의: 기존 팔 메시는 전부 mm 단위 + scale="0.001 0.001 0.001" 입니다.
    새로 뽑으시면 단위가 바뀔 수 있으니 scale 을 URDF 에 정확히 넣어주세요.


 5. 받은 뒤 제가 하는 일
--------------------------------------------------------------------------------
    1. assets/robot_arm_temp/ 에 배치
    2. 06_setup_urdf.py 로 등록 → config/arm_temp.json
    3. ./run.sh --temp 로 임시 팔 텔레옵 실행 (기존 팔 설정은 그대로 보존)
    4. 랭크·작업공간·추종 성능을 재서 결과 공유

  기존 5-DOF 팔 설정(config/arm.json)은 건드리지 않으므로
  ./run.sh 와 ./run.sh --temp 를 오가며 쓸 수 있습니다.
